What changes?04 / 14

Two challenges come with AI.

Challenge 01

Behavior can vary.

The same request can produce different outputs.

Repeat cases. Check reliability.

Challenge 02

“Good” needs a definition.

Different answers can be valid.

Define accuracy, coverage, and clarity.

A repeatable answer can still be wrong.

Choose the check that matches the behavior.06 / 14

When do we use each?

Does arithmetic follow the rounding rule?

Use a software test with the exact expected value.

Does a missing document produce the right error?

Use software tests for loading and error handling.

Is the summary accurate and complete?

Use an AI eval with a factual and quality rubric.

Are the extracted invoice fields correct?

Use an AI eval with exact comparisons to reviewed fields.

Did the agent supply the right tool arguments?

Inspect recorded tool calls against the source invoice.

Did a prompt or model change improve the system?

Run relevant software tests and the same AI eval cases.

An AI application usually needs both. Exact assertions can also be eval checks.
