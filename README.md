# Evals explained

A 40-minute Evals 101 workshop covering software testing, AI output evaluation, a simple invoice agent, and eval-driven development.

## Presentation

Open [index.html](index.html) in a browser. The 14-slide presentation includes a clickable table of contents, collapsible Q&A, interactive examples, and source citations. Use the arrow keys or navigation buttons to move between slides.

The presentation is self-contained and works without a build step or external runtime dependencies.

## Workshop materials

- [Speaker notes](speaker-notes.md): short bullet cues matched to each slide.
- [Content draft](evals-101-content.md): detailed explanations and references used to develop the workshop.

## GitHub Pages

Publish from the `main` branch and repository root (`/`). The `.nojekyll` file lets GitHub serve the static presentation directly.

## References

Sources are linked beside the relevant claims and in the presentation's Sources panel: OpenAI's evaluation guidance and summarization Cookbook, and Rittika Jindal's guide to agent evaluation with Langfuse.
